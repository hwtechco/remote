校验0
开始 / 结束自动创建
结构：开始 → 自定义… → 结束，开始/结束自动创建、名称固定（内容照常可编辑）
语义：开始是入口，其规则决定流程走向；结束是终止，走到此处即停
规则：条件集 + 行动集 + 下一状态 + 切号标记
引用：状态可选「引用」，只存路径（相对 任务/，不写 .yaml 后缀）与返回状态；运行时读该文件当子任务，跑完文件里的「结束」回到该返回状态
默认空值：无条件 = 条件为空（恒成立）· 无行动 = 行动为空（不执行操作）
类型注册表：条件对齐 server/condition 的 7 个类 · 行动对齐 server/action 的 27 个类，可继续扩展
文件：一个任务一个 yaml（文件名为任务名，内容就是该任务的 states）；多任务导出打包成 zip，导入支持 yaml / json / zip
